# Product thesis

Coding capability is becoming abundant. Reliable delegation is not.

The bottleneck for non-technical and technical users is increasingly the ability to state an outcome once and trust that an agent will preserve it, avoid unnecessary work, prove what changed, surface disagreement, and stop honestly.

Signoff's wedge is a repository-local reliability layer that works with the agent already present. The long-term control plane can become the shared protocol for:

- individual developers delegating high-stakes repository work;
- teams applying policy across multiple agent vendors;
- enterprises requiring audit and evidence receipts;
- benchmark operators comparing agent systems on false completion, not demo quality;
- agent marketplaces that need a portable definition of “done.”

The defensible asset is not a prompt. It is the combination of:

1. an easy cross-agent install and one-path user experience;
2. a versioned artifact and state protocol;
3. adversarial conformance fixtures;
4. a growing held-out efficacy dataset;
5. integrations that provide verifiable context/call identities and isolated evidence;
6. observed failure taxonomies that improve stopping, slicing, and proof policies.

The key business and scientific claim must remain falsifiable: Signoff should materially reduce false completion and goal drift without making simple work uneconomic. The included harness exists to test that claim rather than assume it.
