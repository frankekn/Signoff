# Changelog

All notable changes are documented here.

## 0.1.0-alpha.1 — 2026-06-25

- Established Signoff as the product, Court as the deterministic core, Signoff Protocol as the artifact contract, and Receipt as the evidence output.
- Added a local Vite, React, TanStack Router, and TanStack Query control UI.
- Added a dependency-free Python HTTP API and packaged prebuilt UI assets.
- Added POSIX and PowerShell installation scripts plus a disposable working demo.
- Added exact-goal, charter, spec, Council, contract, evidence, patch, review, and judgment hashes.
- Added Git synthetic snapshot baselines without changing the user's branch or index.
- Added path, production-file, and changed-line scope gates.
- Added runtime verification execution and verification-mutation detection.
- Added canonical Council claims and evidence-based conflict closure.
- Added builder/reviewer/judge separation and complete review finding accounting.
- Added a hash-chained ledger, pivot path, cumulative DONE gate, adversarial tests, and efficacy harness.
